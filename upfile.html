BƯỚC ĐẦU TIÊN

Kết nối GitHub của bạn

Dùng Personal Access Token để quản lý file trong kho bạn cho phép.

Cách tạo mã truy cập trên điện thoại
  1. Mở trang tạo token của GitHub ↗ trong trình duyệt.
  2. Đặt tên token, chọn hạn dùng và chủ sở hữu kho (Resource owner).
  3. Trong Repository access, chọn Only select repositories và chọn kho cần quản lý.
  4. Trong Repository permissions, đặt Contents → Read and write. Metadata để mặc định.
  5. Bấm Generate token, sao chép rồi dán vào ô ở trên.

Kho của tổ chức có thể cần quản trị viên duyệt. File trong .github/workflows cần thêm quyền Workflows.

Token được gửi trực tiếp tới api.github.com. Không lưu token vào bộ nhớ trình duyệt; tải lại hoặc đóng trang sẽ cần kết nối lại. Không gửi token qua chat.
